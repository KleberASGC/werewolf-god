# Werewolf God

Assistente web para apoiar mestres durante partidas presenciais de Lobisomem.

## Status

Fundação da aplicação em desenvolvimento. Já é possível cadastrar uma partida com participantes e retomá-la no mesmo navegador. Nenhuma regra de personagem ou mecânica de partida foi implementada ou presumida.

## Executar localmente

Requer Node.js 18 ou superior e npm:

```sh
npm install
npm run dev
```

Para validar a compilação:

```sh
npm run build
```
